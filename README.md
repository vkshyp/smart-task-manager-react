# Smart Task Manager (React)

A beginner-friendly task management web application built using React.

## 🚀 Features
- Add and delete tasks
- Mark tasks as completed
- Set due dates
- Overdue task highlighting
- Filter tasks (All / Completed / Pending)
- Data persistence using Local Storage

## 🛠️ Technologies Used
- React (Hooks)
- JavaScript (ES6)
- CSS
- Local Storage

## 📦 Installation & Run
1. Clone the repository
2. Install dependencies:
   npm install
3. Run the project:
   npm run dev
4. Open browser:
   http://localhost:5173
